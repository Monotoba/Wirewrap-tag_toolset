# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting](https://github.com/Monotoba/Wirewrap-tag_toolset/security/advisories/new)
page instead.

Include the affected version, operating system, reproduction steps, expected impact,
and any suggested mitigation. You should receive an acknowledgment within seven days.
Please allow reasonable time for investigation and a coordinated fix before disclosure.
